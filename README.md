# TruckStop

Магазин аксессуаров и товаров для грузовых автомобилей.
Локация: окружная Тбилиси (продажа с машины + онлайн).

## Стек
- Статический сайт (HTML + Tailwind) в индустриальном стиле (Freitag-inspired)
- Далее можно перейти на Next.js

## Структура
- `public/images/` — логотипы, баннеры, фото товаров
- Основной сайт в корне
